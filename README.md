# CIFAR-10 Image Classification

## 1. Описание задачи

> Задача многоклассовой классификации изображений из датасета CIFAR-10.
> Необходимо классифицировать изображение в один из 10 классов.

В работе исследуется применение сверточной нейронной сети ResNet18
для классификации изображений CIFAR-10 и влияние аугментации данных
на качество модели.

### Используемые подходы

- ResNet18
- Cross-Entropy Loss
- Adam optimizer
- CUDA вычисления 
- Data Augmentation
- YAML-конфигурация экспериментов
- CSV для хранения результатов экспериментов


## 2. Данные

Используется датасет CIFAR-10.

| Параметр | Значение |
|---|---:|
| Train | 50 000 |
| Test | 10 000 |
| Размер изображения | 32 × 32 |
| Каналы | RGB |
| Количество классов | 10 |

### Классы

- airplane
- automobile
- bird
- cat
- deer
- dog
- frog
- horse
- ship
- truck

### EDA

В ходе EDA были исследованы:

- распределение классов;
- размеры и характеристики изображений;
- примеры изображений каждого класса;
- внутриклассовое разнообразие;
- статистики RGB-каналов;
- влияние аугментации.

Основные наблюдения:

- датасет сбалансирован — каждый класс представлен одинаковым
  количеством изображений;
- изображения имеют небольшой размер — 32×32;
- внутри классов присутствует существенное разнообразие
  положения и масштаба объектов;
- некоторые классы визуально близки друг к другу, например `cat` и `dog`,
  `automobile` и `truck`.


## 3. Архитектура модели

В качестве основной модели используется ResNet18.

- вход: RGB изображение 32×32;
- backbone: ResNet18;
- выход: 10 logits;
- функция потерь: Cross-Entropy Loss;
- оптимизатор: Adam.

Для CIFAR-10 архитектура адаптирована под небольшой размер входного изображения.
